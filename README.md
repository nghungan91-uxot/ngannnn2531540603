# Website Ẩm Thực Việt Nam - Hương Vị Việt

Dự án website tĩnh giới thiệu văn hóa ẩm thực truyền thống Việt Nam 3 miền, được xây dựng bằng HTML5 và CSS3 Responsive hoàn chỉnh.

## 1. Cấu trúc thư mục dự án
```text
project/
├── index.html       # Trang chủ
├── about.html       # Trang Giới thiệu
├── products.html    # Trang Thực đơn món ăn
├── services.html    # Trang Dịch vụ
├── gallery.html     # Trang Thư viện ảnh
├── blog.html        # Trang Tin tức & Bài viết
├── details.html     # Trang Chi tiết món ăn
├── contact.html     # Trang Liên hệ & Đặt bàn
├── css/
│   └── style.css    # File CSS dùng chung
└── README.md        # File hướng dẫn dự án
